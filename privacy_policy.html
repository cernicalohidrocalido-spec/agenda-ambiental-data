Datos que recopilamos

Esta aplicación NO recopila datos personales. Todos los datos (eventos, hábitos, diario eco) se almacenan localmente en tu dispositivo.

Lo que NO hacemos

  • No recopilamos nombre, email ni información de contacto
  • No usamos analytics ni rastreo
  • No compartimos datos con terceros
  • No mostramos publicidad

Sincronización de contenido

La app descarga actualizaciones del catálogo de efemérides desde GitHub Pages. Esta descarga no incluye datos personales.

Exportación de datos

La función de exportación genera un archivo JSON en tu dispositivo que nunca se envía a ningún servidor.
